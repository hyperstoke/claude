Для тем из уровня «знаком, но не закреплено» (списки, comprehensions,
map/lambda, словари и т.д.) пользователь выбрал режим ревью **«мягко
подталкивать»** (2026-07-13).

**Why:** он видел эти конструкции через ChatGPT с опережением программы
Stepik, но по собственным словам не переварил их. Подавать их как
единственно верное решение — рано и запутает.

**How to apply:** основным решением на ревью оставлять уровень, который
он уже прошёл; продвинутый вариант (comprehension / map) иногда
показывать как бонус «на вырост», не настаивая. Источник правды по
уровням — `study_python/coach/known_topics.md`. См. [[chatgpt-export-processed]].
