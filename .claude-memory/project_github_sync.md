Папка `/Users/folder/Documents/claude` — git-репозиторий с remote
`origin` → приватный репозиторий `https://github.com/hyperstoke/claude`
(ветка `main`). Настроено 13 июля 2026 по просьбе пользователя.
Изначально задумывалось как синхронизация между двумя устройствами;
2026-09-09 пользователь подтвердил, что машина одна — MacBook, — так что
репозиторий работает как резервная копия и история, а не как синхронизация.

Детали:
- GitHub-аккаунт пользователя: **hyperstoke**.
- `gh` CLI v2.96.0 установлен в `~/.local/bin/gh` на Mac; в PATH его
  может не быть (правка ~/.zshrc была отклонена пермишенами) — вызывать
  по полному пути. Авторизация через keyring, git credential helper
  настроен (`gh auth setup-git`).
- Рабочий процесс: commit + `git push` по просьбе или в конце сессии
  (описан в CLAUDE.md репозитория, раздел «Синхронизация через GitHub»).
  `git pull` в обычной работе не нужен — писать в репозиторий больше
  некому.
- Пользователю важно: приватность (никому кроме него не виден) и
  минимальный расход токенов — синхронизация только через git-команды,
  не через браузер.
- С 16 июля 2026 автоматическая память Claude Code тоже в репо:
  каталог `.claude-memory/` в корне, на Mac каталог памяти проекта
  заменён симлинком на него. Изменения памяти коммитить вместе с
  остальными при «сохрани на GitHub». `SYNC_MEMORY.md` описывает настройку
  памяти на новом устройстве — сейчас неактуален, но пригодится при
  переезде.
