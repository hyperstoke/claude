Не трогать `study_python/coach/activity.json`, `coach/practice_queue.json` и
`study_python/roadmap_artifact.html` по собственной инициативе. Обновлять только
когда пользователь говорит, что занятие закончено, или прямо просит сохранить
прогресс — всё одним заходом.

**Why:** 2026-08-26 на запрос «проверь мой код» Claude после проверки полез
обновлять журнал и перезаливать артефакт; перезаливка потребовала вычитать
опубликованный HTML целиком (440 КБ). Пользователь: «а то ты жжешь мои токены».
Правило «писать СРАЗУ» в `study_python/CLAUDE.md` было причиной — там же
исправлено (раздел «Отслеживание прогресса — только по просьбе пользователя»).

**How to apply:** проверка задач, ревью и разбор идут как обычно — без записи в
журнал. Детект слабых тем держать в голове по ходу занятия, на диск писать в
конце. Перезаливка артефакта — самая дорогая операция, только в этом заходе.
Связано с [[project_github_sync]] (пуш тоже по просьбе).
