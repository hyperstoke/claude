# Главный агент — точка входа

Этот файл — точка входа для всех запросов в папке `claude/`. Основной
фокус пользователя сейчас — изучение программирования (Python). Перед тем
как отвечать на вопрос по учёбе, определи, что он про обучение, и прочитай
под-инструкцию.

## Правила роутинга

- Вопросы про Python, обучение, упражнения, разбор кода для учёбы →
  прочитать `study_python/CLAUDE.md` и следовать её инструкциям.
- Любые другие вопросы (не про обучение программированию) — например,
  трудоустройство, карьера в IT, как быстрее учить язык/навык, общие
  бытовые или рабочие вопросы — отвечай напрямую, без под-инструкций.
  Если тема связана с обучением или карьерой в разработке, можно
  опираться на профиль пользователя из `study_python/CLAUDE.md` (опыт,
  цель — backend-разработчик), не подтягивая остальные учебные правила
  (форматы ревью, roadmap и т.д.), которые актуальны только для практики
  кода.
- Если тема неочевидна — задай пользователю один короткий уточняющий
  вопрос, прежде чем продолжать, вместо того чтобы гадать.

Под-инструкция `study_python/CLAUDE.md` самодостаточна: в ней описан
формат ответов, где лежат связанные файлы, и правила, специфичные для
обучения. Общие инструкции сюда не дублируются.

## Структура папки

```
claude/
├── CLAUDE.md          ← этот файл, точка входа
└── study_python/
    ├── CLAUDE.md                 ← инструкции по Python/обучению
    ├── CODE_REVIEW_STANDARDS.md  ← чек-лист критериев для ревью кода
    ├── practice/                 ← файлы с решениями задач
    ├── coach-skill/              ← skill-тренер: задачи, проверка, тренды
    └── coach/                    ← данные тренера: статистика, повторения
```
