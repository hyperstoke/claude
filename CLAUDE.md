# Главный агент — точка входа

Этот файл — точка входа для всех запросов в папке `claude/`. Основной
фокус пользователя сейчас — изучение программирования (Python). Перед тем
как отвечать на вопрос по учёбе, определи, что он про обучение, и прочитай
под-инструкцию.

## Правила роутинга

- Вопросы про Python, обучение, упражнения, разбор кода для учёбы →
  прочитать `study_python/CLAUDE.md` и следовать её инструкциям.
- Любые другие вопросы (не про обучение программированию) — например,
  трудоустройство, карьера в IT, как быстрее учить язык/навык, общие
  бытовые или рабочие вопросы — отвечай напрямую, без под-инструкций.
  Если тема связана с обучением или карьерой в разработке, можно
  опираться на профиль пользователя из `study_python/CLAUDE.md` (опыт,
  цель — backend-разработчик), не подтягивая остальные учебные правила
  (форматы ревью, roadmap и т.д.), которые актуальны только для практики
  кода.
- Если тема неочевидна — задай пользователю один короткий уточняющий
  вопрос, прежде чем продолжать, вместо того чтобы гадать.

Под-инструкция `study_python/CLAUDE.md` самодостаточна: в ней описан
формат ответов, где лежат связанные файлы, и правила, специфичные для
обучения. Общие инструкции сюда не дублируются.

## Источники информации — приоритет

При вопросе, требующем фактов, идти сверху вниз; спускаться ниже, только
если уровень выше не дал ответа:

1. Локальные файлы проекта и память.
2. Кэш исследований `study_python/research/` (проверить `INDEX.md` и свежесть).
3. Знания модели — для стабильных фактов (синтаксис Python, PEP8, алгоритмы).
4. `gh` CLI / git — всё про GitHub (репозитории, релизы, issues).
5. WebFetch — известен точный URL статичной страницы.
6. Firecrawl CLI (search/scrape/map) — нужен веб-поиск, JS-сайты или антибот.

Firecrawl — только для нестабильных фактов (тренды, вакансии, версии,
релизы, выбор актуальных материалов). Условия запуска, команды и правила
кэширования — `study_python/research-skill/SKILL.md`; при таких запросах
(«найди», «загугли», «исследуй», «что сейчас актуально», «собери конспект
по документации») прочитать этот skill и следовать ему.

## Синхронизация через GitHub

Папка — git-репозиторий, синхронизируется через приватный репозиторий
`https://github.com/hyperstoke/claude` (remote `origin`, ветка `main`).
Пользователь работает с двух устройств (Mac и ПК).

- Если пользователь просит «подтяни изменения», «синхронизируй» или
  говорит, что работал на другом устройстве — выполни `git pull`.
- Если просит «сохрани», «выгрузи на GitHub» — закоммить изменения
  (краткое сообщение по-русски) и выполни `git push`.
- В конце сессии с изменёнными файлами — предложи отправить их на GitHub,
  но не пуш без согласия пользователя.
- На Mac `gh` установлен в `~/.local/bin/gh` (может отсутствовать в PATH).
- Автоматическая память Claude Code лежит в `.claude-memory/` и тоже
  синхронизируется через git (каталог памяти устройства — симлинк сюда).
  Настройка нового устройства — см. `SYNC_MEMORY.md`.

## Структура папки

```
claude/
├── CLAUDE.md          ← этот файл, точка входа
├── SYNC_MEMORY.md     ← как устроена синхронизация памяти между устройствами
├── .claude-memory/    ← автоматическая память Claude Code (симлинк с устройств)
└── study_python/
    ├── CLAUDE.md                 ← инструкции по Python/обучению
    ├── CODE_REVIEW_STANDARDS.md  ← чек-лист критериев для ревью кода
    ├── practice/                 ← файлы с решениями задач
    ├── coach-skill/              ← skill-тренер: задачи, проверка, тренды
    ├── coach/                    ← данные тренера: статистика, повторения
    ├── research-skill/           ← skill веб-исследований (Firecrawl, кэш)
    └── research/                 ← кэш исследований: INDEX.md + отчёты
```
