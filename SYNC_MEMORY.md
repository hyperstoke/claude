# Память Claude Code в этом репозитории

Каталог `.claude-memory/` в корне — это автоматическая память Claude Code
для проекта `claude/`. Настоящий каталог памяти
(`~/.claude/projects/<ключ-проекта>/memory`) заменён симлинком на эту папку,
поэтому память попадает в git вместе с остальными файлами.

Работа идёт с одного устройства — MacBook (симлинк настроен 2026-07-16).
GitHub здесь резервная копия и история, а не синхронизация между машинами.

## Правила

- Память пишется автоматически по ходу сессий, поэтому в `git status` часто
  будут изменения в `.claude-memory/` — коммитить их вместе с остальным при
  «сохрани на GitHub».
- История чатов этим НЕ сохраняется — только память.

## Если появится новая машина

Инструкция ниже нужна только при переезде или добавлении второго устройства.
Проще всего: открыть эту папку в Claude Code и сказать — «Прочитай
SYNC_MEMORY.md и настрой симлинк памяти на этом устройстве».

1. Найти каталог памяти этого проекта. Путь указан в системном промпте
   агента (секция Memory), вида `~/.claude/projects/<ключ>/memory`.
2. Если в нём уже есть свои заметки — перенести файлы в `.claude-memory/` и
   дописать их строки в `MEMORY.md`, не затирая существующие. При совпадении
   имён — объединить содержимое вручную.
3. Переименовать старый каталог в `memory.bak` и создать на его месте
   симлинк: `ln -s <путь-к-репо>/.claude-memory <путь-к-каталогу-памяти>`.
4. Проверить, что `MEMORY.md` читается по старому пути через симлинк.
5. Закоммитить.

При работе с двух машин добавится `git pull` в начале сессии — иначе будут
конфликты в файлах памяти.
