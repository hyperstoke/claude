# Синхронизация памяти Claude Code между устройствами

Каталог `.claude-memory/` в корне репозитория — это автоматическая память
Claude Code для проекта `claude/`. На каждом устройстве настоящий каталог
памяти (`~/.claude/projects/<ключ-проекта>/memory`) заменён симлинком на
эту папку, поэтому память ездит между устройствами через git вместе с
остальными файлами.

## Статус настройки

- [x] Mac — настроено 2026-07-16 (`~/.claude/projects/-Users-folder-Documents-claude/memory` → симлинк)
- [x] ПК — настроено 2026-07-20 (`C:\Users\Admin\.claude\projects\c--Users-Admin-Documents-claude\memory` → junction на `.claude-memory`; старый каталог сохранён как `memory.bak`)

## Как настроить на новом устройстве

Проще всего: открыть эту папку в Claude Code и сказать —
«Прочитай SYNC_MEMORY.md и настрой симлинк памяти на этом устройстве».

Инструкция для агента (или вручную):

1. Найти свой каталог памяти этого проекта. Его путь указан в системном
   промпте агента (секция Memory), вида
   `~/.claude/projects/<ключ-из-пути-проекта>/memory`.
2. Если в нём уже есть свои заметки — перенести их файлы в
   `.claude-memory/` в репозитории и дописать их строки в `MEMORY.md`
   (не затирая существующие). При совпадении имён файлов — объединить
   содержимое вручную.
3. Удалить (переименовать в `memory.bak` до проверки) старый каталог и
   создать на его месте симлинк на `<путь-к-репо>/.claude-memory`:
   - macOS/Linux: `ln -s <путь-к-репо>/.claude-memory <путь-к-каталогу-памяти>`
   - Windows (cmd, без прав администратора):
     `mklink /J <путь-к-каталогу-памяти> <путь-к-репо>\.claude-memory`
4. Проверить: `MEMORY.md` читается по старому пути через симлинк.
5. Отметить устройство в чек-листе выше и закоммитить.

## Правила

- Память пишется автоматически по ходу сессий, поэтому в `git status`
  часто будут изменения в `.claude-memory/` — коммитить их вместе с
  остальным при «сохрани на GitHub».
- Начинать работу на устройстве с `git pull`, чтобы не ловить конфликты
  в файлах памяти.
- История чатов этим НЕ синхронизируется — только память.
