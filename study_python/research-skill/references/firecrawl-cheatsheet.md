# Firecrawl CLI — шпаргалка (проверено на v1.19.26, 2026-07-15)

Установлен глобально через npm (`npm install -g firecrawl-cli`).
Ключ берётся из `FIRECRAWL_API_KEY`. На ПК (Windows) node/npm лежат в
`%LOCALAPPDATA%\Programs\nodejs` и `%APPDATA%\npm` — оба в user PATH;
если свежезапущенный процесс их не видит, добавить в PATH вручную.

## search — поиск (основная команда)

```
firecrawl search "python backend best practices 2026" --limit 5 --tbs qdr:y
```

- `--limit N` — число результатов (по умолчанию 5). Больше 5 — почти никогда.
- `--tbs qdr:y | qdr:m | qdr:w` — только за последний год/месяц/неделю.
  Для трендов ставить всегда.
- `--scrape` — сразу вернуть контент найденных страниц (экономит второй
  шаг, но дороже: кредит за каждую соскрейпленную страницу — включать,
  когда результаты точно нужны целиком).
- `--location "Russia"` — гео-таргетинг выдачи (для запросов про рынок РФ).
- `--categories github,research,pdf` — фильтр типов источников.
- `-o файл.md` — вывод сразу в файл, мимо контекста.

## scrape — одна страница в markdown

```
firecrawl scrape https://habr.com/ru/articles/NNN/ --only-main-content -o research/raw.md
```

- `--only-main-content` — без шапок/меню. Включать всегда (по умолчанию
  у scrape ВЫКЛЮЧЕН, в отличие от search).
- `--max-age 604800000` — принять кэш Firecrawl до 7 дней (мс): дешевле
  и быстрее при повторном обращении к тому же URL.
- `--wait-for 3000` — подождать JS-рендеринг (мс), если страница пустая.
- `-Q "вопрос"` — задать вопрос по странице вместо полного текста
  (когда нужен один факт, а не вся статья).
- Несколько URL позиционно — скрейпятся параллельно, падают в `.firecrawl/`
  (папка создаётся в текущей директории — запускать НЕ из корня репо
  или добавить `.firecrawl/` в .gitignore).

## map — список URL сайта (разведка перед конспектом)

```
firecrawl map https://fastapi.tiangolo.com --search "tutorial" --limit 50
```

- `--search слово` — отфильтровать URL по теме.
- `--limit N` — обязательно ставить.
- Дёшево. Всегда делать map перед скачиванием нескольких страниц,
  чтобы скрейпить только нужные.

## Что НЕ использовать

- `crawl` — обход всего сайта. Только по явной просьбе пользователя.
- `agent`, `interact`, `monitor` — не нужны проекту; monitor — это
  регулярные платные проверки, наш ритм задаёт расписание трендов.
- `extract`/`--schema` — структурированное извлечение; допустимо в виде
  исключения, когда нужна именно таблица данных (например, «навык →
  частота в вакансиях»), это дороже обычного scrape.

## Служебное

- `firecrawl credit-usage` — остаток кредитов (бесплатный план: 1000).
- `firecrawl version` — версия CLI.
