Пузырёк — самый простой алгоритм сортировки: сравнить двух соседей, при необходимости поменять местами, повторять. Визуализатор ниже показывает, какая строка кода выполняется на каждом шаге; дальше — четыре способа записать пузырёк, от наивного до шейкерного.

Идея за минуту

Идём по массиву слева направо и смотрим на пары соседних элементов — left и right. Если left больше — меняем их местами. За один проход самый большой элемент «всплывает» в конец, как пузырёк, — отсюда название. Повторяем проходы; когда за целый проход не случилось ни одного обмена, массив уже упорядочен.

Визуализатор

Столбик — число. Переключай варианты кнопками сверху; панель справа подсветит активную строку. Над сравниваемой парой — имена из кода (left / right) и индексы (i / i + 1); у шейкерной снизу отмечены границы start и end — докуда дошёл ещё не отсортированный кусок.

Четыре варианта

  
Идея одна; отличается только объём лишней работы. Первые три — тот же пузырёк с
    постепенной экономией, четвёртый носит собственное имя.


  

    
1 · базовыйдва вложенных цикла

    
def bubble_sort(numbers):
    length = len(numbers)
    for _ in range(length - 1):
        for i in range(length - 1):
            left = numbers[i]
            right = numbers[i + 1]
            if left > right:
                numbers[i], numbers[i + 1] = right, left
    return numbers

  

  
Внешний цикл — length − 1 проход, внутренний каждый раз идёт по всему
    массиву. Даже если данные уже отсортированы, делает все (length − 1)²
    сравнений. Отправная точка, дальше — три улучшения.


  

    
2 · не трогаем хвостrange(… − placed)

    
def bubble_sort(numbers):
    length = len(numbers)
    for placed in range(length - 1):
        for i in range(length - 1 - placed):
            left = numbers[i]
            right = numbers[i + 1]
            if left > right:
                numbers[i], numbers[i + 1] = right, left
    return numbers

  

  
После прохода номер placed столько же наибольших элементов уже стоят в
    конце на своих местах — сравнивать их снова незачем. Одна цифра в range,
    сравнений почти вдвое меньше: length·(length − 1) / 2. В визуализаторе
    видно, как хвост подсвечивается «на месте».


  

    
3 · флаг раннего выходапо умолчанию — так

    
def bubble_sort(numbers):
    length = len(numbers)
    for placed in range(length - 1):
        swapped = False
        for i in range(length - 1 - placed):
            left = numbers[i]
            right = numbers[i + 1]
            if left > right:
                numbers[i], numbers[i + 1] = right, left
                swapped = True
        if not swapped:
            break
    return numbers

  

  
Флаг swapped: если за целый проход не было ни одного обмена, массив
    упорядочен и break прекращает работу. На отсортированном входе — один
    проход, O(n) вместо O(n²). Канонический вариант: по умолчанию
    пиши так.


  

    
4 · шейкернаяcocktail sort

    
def cocktail_sort(numbers):
    start = 0
    end = len(numbers) - 1
    swapped = True
    while swapped:
        swapped = False
        for i in range(start, end):
            left = numbers[i]
            right = numbers[i + 1]
            if left > right:
                numbers[i], numbers[i + 1] = right, left
                swapped = True
        end -= 1
        for i in range(end, start, -1):
            left = numbers[i - 1]
            right = numbers[i]
            if left > right:
                numbers[i - 1], numbers[i] = right, left
                swapped = True
        start += 1
    return numbers

  

  
Обычный пузырёк быстро гонит большие элементы вправо, а маленькие ползут влево по
    одному за проход — их называют «черепахами». Шейкер после прохода вправо идёт обратно
    влево и утаскивает мелкие к началу. На данных с «черепахами» заметно быстрее; в худшем
    случае — та же O(n²). Формально это уже отдельный алгоритм, но вырастает
    прямо из пузырька.

Пузырёк устойчивый: равные элементы не перепрыгивают друг через друга, потому
    что обмен происходит только при строгом >. Память O(1) —
    сортируем на месте, без второго массива.


  
Когда пузырёк уместен

  
    
    
  • Почти отсортированные данные. С флагом раннего выхода — один-два прохода,
      быстрее многих «умных» сортировок с их накладными расходами.
    • 
    
  • Крошечные массивы и учебные задачи. На десятке элементов разница с
      O(n log n) незаметна, а кода — четыре строки.
    • 
    
  • В реальном коде — не он. sorted(x) и x.sort()
      используют TimSort — гибрид вставок и слияния, устойчивый, O(n log n)
      в худшем случае. Пузырёк пишут, чтобы понять, как сортировка устроена изнутри.
    • 
  


  

    Существует ещё рекурсивная запись: один проход пузырька плюс вызов функции для
    массива на элемент короче. Та же работа тем же способом, просто цикл заменён рекурсией.
    Вернёшься к ней после темы «рекурсия».
