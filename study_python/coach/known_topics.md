Список разбит на три уровня, потому что через ChatGPT ты забегал вперёд

закрепил. Уровни нужны, чтобы на ревью не предлагать тебе конструкции,
которые ты пока не переварил.

## 1. Уверенно владею (можно опираться как на основу)

- Типы данных: int, float, str, bool; преобразования типов.
- Ввод/вывод: input(), print() (sep, end), множественное присваивание
  (`a, b = input(), input()`).
- f-строки, включая форматирование ширины/нулей: `f"{h:02}:{m:02}"`.
- Арифметика: `//`, `%`, `**`, round(), abs(), min(), max(); разбор числа
  по цифрам через `% 10` и `// 10`.
- Условный оператор: if/elif/else, and/or/not, оператор `in`, цепочки
  сравнений (`1 <= x <= 8`).
- Тернарная запись `x if cond else y` — много практиковал
  (`total += i if i % 2 else -i`), читает и пишет.
- Циклы: for/while, range() со стартом/шагом/отрицательным шагом,
  break/continue/else, вложенные циклы, флаг-паттерн (`flag = False … `),
  накопители (sum/произведение/счётчик), паттерн `x is None or x > max`.
- Строки: индексация, срезы `s[a:b:c]` (включая `s[::-1]`), конкатенация
  и умножение, len(), сравнение строк.
- Методы строк (тема 9.3): upper, lower, count, find, rfind, index,
  replace, strip/lstrip/rstrip, startswith, endswith (в т.ч. с кортежем
  окончаний: `s.endswith(("2","5","8"))`).

### Добавлено 2026-08-27 — пройдено на курсе после 13 июля

Разделы 10 «Списки» и «Функции» (12.1 полностью, 12.2 в процессе) закрыты
практикой, поэтому конструкции ниже переехали сюда из блока 2. На них можно
опираться как на основу, а не подавать «на вырост»:

- Списки: `[]`, `.append()`, `.extend()`, `.insert()`, `.index()`, `.count()`,
  `.remove()`, `.pop()`, `del`, `.sort(reverse=...)`, `sorted()`, срезы
  списка, `lst[-1]`, `list(map(int, ...))`, `list(range(a, b, step))`.
  Разница «метод меняет на месте и возвращает None» против «функция
  возвращает новый список» разобрана и применяется.
- Списочные выражения, в том числе с фильтром:
  `[x for x in xs if cond]`, `[f(x) for x in range(n)]`. Отличие от
  генераторного выражения в круглых скобках разобрано трижды, последняя
  проверка (25 августа) прошла без ошибки.
- Встроенные с итерируемыми: `sum()`, `all()`, `min`/`max` с `key=`, `len()`,
  `enumerate()`, распаковка `print(*lst, sep=...)`, `"".join(...)`.
- Функции: `def` с параметрами, `return` (в т.ч. возврат выражения-сравнения
  напрямую), ранний выход, `None` как неявный результат, контракт заголовка
  (имя функции и имена параметров задаёт условие задачи).
- `%` для нормализации по кругу: `(hour + offset) % 24`, приоритет `%` выше `+`.
- Ручные сортировки: пузырёк с флагом обмена и выбором минимума — **написаны
  по эталону, самостоятельно не воспроизводятся** (см. очередь закрепления).

## 2. В процессе освоения — видел, НЕ закреплено

Режим ревью: **мягко подталкивать**. Основным решением оставляю уровень
из блока 1; эти конструкции можно иногда показывать как бонус «на вырост»,
но не подавать как единственно правильные, пока тема не пройдена на Stepik.

- Словари: базовый `{ключ: значение}`, доступ по ключу, `.items()`,
  `sorted(d.items())`. Применено ровно один раз («Посчитай количества»,
  16 августа); `.get(key, 0)` для накопления счётчиков ещё не разбирался.
- Кортежи: отличие от списка (изменяемость), распаковка.
- `map()`, `filter()` + `lambda` — `map(int, ...)` применяется уверенно,
  `filter`/`lambda` видел, но в решениях не появлялись.
- Модуль math: import, `math.factorial`, `math.pow`, `math.log`,
  `math.sqrt`, `math.floor`; `import math` vs `from math import *`.
  Отдельная линия: тяга брать готовую функцию там, где хватает встроенной
  операции (`round`, `floor`/`ceil`, `fmod`, `bool()` вокруг сравнения).
- `float('inf')` / `-float('inf')` как стартовое значение для min/max.
- Погрешность float: всплывала дважды (20 и 21 августа), не закреплена.

## 3. Не трогал — предлагать рано

- `zip()` (обход двух последовательностей сразу).
- Тайп-хинты (`def f(word: str) -> bool`) — уместно предложить на текущей
  теме «Функции» как бонус.
- Исключения (try/except).
- Работа с файлами.
- ООП (классы), декораторы, генераторы (yield), context managers.

## Заметки на будущее (не про синтаксис)

- CS-осознанность: постоянно спрашивает про асимптотику — O(1), O(n),
  O(n²). Мышление о сложности уже включено, хотя формально это вне
  базового курса. Можно опираться при объяснении «почему так лучше».
