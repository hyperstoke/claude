# Что уже изучено (источник правды для проверки оптимальности)

Собрано из прогресса Stepik на 2026-07-12. Денис, проверь и поправь —
skill сравнивает твои решения только с этим списком.

- Типы данных: int, float, str, bool; преобразования типов.
- Ввод/вывод: input(), print() (sep, end), f-строки.
- Арифметика: // , %, **, round(), abs(), min(), max().
- Условный оператор: if/elif/else, логические and/or/not, оператор in,
  тернарная запись пока НЕ пройдена.
- Циклы: for/while, range(), break/continue, вложенные циклы.
- Строки: индексация, срезы s[a:b:c] (включая отрицательный шаг s[::-1]),
  конкатенация и умножение, len(), сравнение строк.
- Методы строк (часть 1, тема 9.3 — в процессе): upper, lower, count,
  find, rfind, index, replace, strip/lstrip/rstrip, startswith, endswith.
- НЕ пройдено (не предлагать как «оптимальное»): split/join, списки,
  кортежи, словари, функции (def), enumerate, sum() по коллекциям,
  comprehensions, исключения, файлы.
