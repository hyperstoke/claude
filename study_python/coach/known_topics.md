# Что уже изучено (источник правды для проверки оптимальности)

Собрано из прогресса Stepik + разбора экспорта чатов с ChatGPT (обучение
май–июль 2026). Обновлено 2026-07-13. Денис, проверь и поправь — skill
сравнивает твои решения с этим списком.

Список разбит на три уровня, потому что через ChatGPT ты забегал вперёд
программы Stepik: многое **видел**, но по собственным словам ещё не
закрепил. Уровни нужны, чтобы на ревью не предлагать тебе конструкции,
которые ты пока не переварил.

## 1. Уверенно владею (можно опираться как на основу)

- Типы данных: int, float, str, bool; преобразования типов.
- Ввод/вывод: input(), print() (sep, end), множественное присваивание
  (`a, b = input(), input()`).
- f-строки, включая форматирование ширины/нулей: `f"{h:02}:{m:02}"`.
- Арифметика: `//`, `%`, `**`, round(), abs(), min(), max(); разбор числа
  по цифрам через `% 10` и `// 10`.
- Условный оператор: if/elif/else, and/or/not, оператор `in`, цепочки
  сравнений (`1 <= x <= 8`).
- Тернарная запись `x if cond else y` — много практиковал
  (`total += i if i % 2 else -i`), читает и пишет.
- Циклы: for/while, range() со стартом/шагом/отрицательным шагом,
  break/continue/else, вложенные циклы, флаг-паттерн (`flag = False … `),
  накопители (sum/произведение/счётчик), паттерн `x is None or x > max`.
- Строки: индексация, срезы `s[a:b:c]` (включая `s[::-1]`), конкатенация
  и умножение, len(), сравнение строк.
- Методы строк (тема 9.3): upper, lower, count, find, rfind, index,
  replace, strip/lstrip/rstrip, startswith, endswith (в т.ч. с кортежем
  окончаний: `s.endswith(("2","5","8"))`).

## 2. В процессе освоения — видел через ChatGPT, НЕ закреплено

Режим ревью: **мягко подталкивать**. Основным решением оставляю уровень
из блока 1; эти конструкции можно иногда показывать как бонус «на вырост»,
но не подавать как единственно правильные, пока тема не пройдена на Stepik.

- Списки: `[]`, `.append()`, `.index()`, `.sort()`, `.reverse()`,
  индексация `lst[-1]`, `list(str(n))`, `list(map(int, ...))`.
- Кортежи: отличие от списка (изменяемость), распаковка.
- Словари: базовый `{ключ: значение}`, доступ по ключу.
- Генераторные выражения и списковые включения:
  `sum(x for x in nums if x > 0)`, `[i for i in range(n)]`.
- Встроенные с итерируемыми: sum(), all(), sorted(), min/max с `key=len`.
- map(), filter() + lambda, split(), join() с генераторным выражением
  (`"".join(ch for ch in s if ch.isalpha())`) — введено и разобрано
  2026-07-22 на задаче «Необычное сравнение», один раз применено успешно.
- Модуль math: import, `math.factorial`, `math.pow`, `math.log`,
  `math.sqrt`, `math.floor`; `import math` vs `from math import *`.
- `float('inf')` / `-float('inf')` как стартовое значение для min/max.

## 3. Не трогал — предлагать рано

- Функции (`def`, return, аргументы) — в чатах ни одной, тема впереди.
- enumerate, zip.
- Исключения (try/except).
- Работа с файлами.
- ООП (классы), декораторы, генераторы (yield), context managers.

## Заметки на будущее (не про синтаксис)

- CS-осознанность: постоянно спрашивает про асимптотику — O(1), O(n),
  O(n²). Мышление о сложности уже включено, хотя формально это вне
  базового курса. Можно опираться при объяснении «почему так лучше».
