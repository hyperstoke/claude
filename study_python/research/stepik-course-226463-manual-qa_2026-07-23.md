## Что удалось установить
- Название: «Ручной Тестировщик ПО / QA manual». Уровень — для начинающих
  с нуля.
- **Программа (из промо):** чек-листы, тест-кейсы, баг-репорты; системы
  тест-менеджмента и баг-трекинга; работа с HTTP-запросами в Postman.

## НЕ подтверждено (уточнить на странице)
- Цена, объём (часы/уроки), рейтинг и число отзывов.
- Есть ли **SQL** (часто требуют junior QA — критично).
- Есть ли практика/тренажёр (у автора есть смежный «Тренажер Тестирование
  ПО / QA manual», id 225415).
- Помощь с трудоустройством / сертификат (для self-paced Stepik — обычно нет).

## Оценка (содержание vs рынок)
Ядро для junior manual закрывает: тест-документация (чек-листы/кейсы/баг-
репорты), баг-трекинг/тест-менеджмент (аналог Jira), Postman/HTTP (API).
Вероятные пробелы: **SQL**, Linux/DevTools, и (ожидаемо для «manual»-курса)
**нет автоматизации**.

**Вывод:** как фундамент — подходит, содержание релевантное. Для
трудоустройства — необходимо, но НЕ достаточно: на перегретом junior-рынке
(см. manual-qa-junior-market_2026-07-23.md) один вводный курс работу не даёт.
Сверху нужны SQL, много практики + портфолио (примеры тест-документации), и
со временем автоматизация. Self-paced Stepik-курс даёт знания, не оффер —
поиск работы ведёшь сам.
