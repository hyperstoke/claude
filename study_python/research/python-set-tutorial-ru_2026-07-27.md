## Выжимка

Для задачи «без дубликатов» (сохранить порядок, убрать повторы) из всего
материала по `set` нужны только: создание (`set()`, `{...}`), `.add(x)`,
проверка `x in s`. Остальное (объединения, пересечения, разности) — на
будущее, не для этой задачи.
