## Полная программа (по словам ученика)
1. **Сети/веб-основы:** QA/QC/тестирование; сети; типы веб-приложений;
   клиент-серверная и микросервисная архитектура; кластеры/балансировщики;
   URL/URI/URN; REST/SOAP/gRPC/GraphQL; HTTP; websockets/вебхуки; кэш/куки;
   идентификация/аутентификация/авторизация; «что происходит после ввода
   адреса»; DevTools. + вопросы с собеседований.
2. **SDLC/методологии:** Agile, Scrum, Kanban, фазы SDLC, STLC, shift-left;
   TMS. + вопросы с собеседований.
3. **Виды тестирования:** функц./нефункц., по коду/доступу/уровню; пирамида
   тестирования; l10n/i18n; техники. + вопросы.
4. **Тест-документация (ядро):** тест-план, чек-лист, тест-кейс/сьют,
   баг-репорт; тест-анализ; **техники тест-дизайна**; тестирование форм;
   метрики; импакт-анализ. **Практика:** тест формы, «найди баги»,
   тестирование требований, тест-документация в **QASE**. + вопросы.
5. **GUI:** HTML/CSS, компоненты UI.
6. **API:** что такое API, Postman, Swagger UI. **Практика:** коллекция в
   Postman.
7. **БД/SQL:** базы данных, SQL + вопросы с собеседований. ← был пробел,
   ЗАКРЫТ.
8. **Мобильное тестирование:** симуляторы/эмуляторы, чек-лист, **Charles
   Proxy** + практика.
9. **Логи.**
10. **Git:** установка, основные команды, вопросы.
11. **Автоматизация (вводно):** Python для автоматизации, первый
    автотест. ← мост к плану ученика.
12. **Трудоустройство:** где искать работу, переговоры с HR, **резюме с
    примерами**, red flags компаний, примеры тестовых заданий с собесов.

## Пересмотренная оценка
Ранее (по промо) выделял пробелы: SQL, автоматизация, помощь с работой. По
полной программе **все три закрыты**: SQL есть, есть вводная автоматизация на
Python, есть целый модуль по трудоустройству (резюме/HR/тестовые задания).
Плюс **«вопросы с собеседований» почти в каждом модуле** — прямая подготовка
к собесу, а это и есть узкое место на перегретом рынке.

Покрытие ≈ полный чек-лист junior manual QA из среза рынка
(manual-qa-junior-market_2026-07-23.md): сети/HTTP/API, SDLC, тест-дизайн,
документация с практикой, SQL, Postman, мобилки, Git, интервью-подготовка.

**Оговорки (честно):**
- Self-paced: модуль трудоустройства = знания/гайд, НЕ менторство,
  рефералы или гарантия оффера. Оффер всё равно за счёт своей практики и
  настойчивости.
- Глубина на Stepik вводная: SQL/автоматизация — «до уровня junior-собеса»,
  не глубоко. Для реальной automation-ветки нужен отдельный курс
  (напр. Python+Playwright, id 266284).
- Практики немного (несколько заданий) — портфолио добираешь сам.

**Вывод:** для обучения — очень подходит, структура и охват сильные. Для
трудоустройства — один из лучших вариантов «одним курсом»: закрывает и
теорию, и SQL, и подготовку к собесу. Но это фундамент+подготовка, а не
гарантия; на перегретом рынке решают ещё практика/портфолио и упорство.
Хорошо ложится на план «manual → automation → Python» (есть Git и
Python-автотест как мост).
