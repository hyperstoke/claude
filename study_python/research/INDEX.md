# Индекс исследований (кэш)

Перед любым веб-поиском — проверить этот индекс: возможно, ответ уже есть
и не устарел. Кэш коммитится в git и синхронизируется между Mac и ПК —
исследование с одного устройства переиспользуется на другом.

Формат записи:

`- [тема](файл.md) — YYYY-MM-DD, TTL: N дней | бессрочно — краткий хук`

TTL по типам:
- тренды, вакансии, «что сейчас актуально» — 30 дней;
- учебные материалы этапа roadmap — до конца этапа;
- changelog, факты о вышедших релизах — бессрочно (история не меняется).

Просроченная запись ≠ удалить: при обновлении перезаписать файл и строку,
прошлая версия — материал для честного «что изменилось».
