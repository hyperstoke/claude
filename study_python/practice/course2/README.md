# Курс 2 — «Поколение Python: курс для продвинутых» (Stepik)

Практика по второму курсу. Разделы первого курса остаются на верхнем уровне
`practice/` (`09_`…`13_`), второй курс — здесь.

## Именование

Как в первом курсе: подпапки разделов `NN_Название_раздела` (транслит,
нумерация с `01`), подпапки тем внутри раздела — `NN_MM_Название_темы`.
Имена `.py`-файлов задач без числового префикса — тема видна из пути.

## Темы курса

1. типы данных `bool` и `NoneType`;
2. вложенные списки и матрицы;
3. кортежи, тип `tuple`;
4. множества, тип `set`;
5. словари, тип `dict`;
6. случайные числа, модуль `random`;
7. дополнительные возможности строк, модуль `string`;
8. числовые типы `decimal`, `Fraction`, `complex`;
9. графика, модуль `turtle`;
10. дополнительные возможности функций;
11. текстовые файлы.
